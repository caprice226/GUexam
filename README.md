# 泌尿科核心課程 離線複習系統

單一 HTML 檔的泌尿科核心課程 / 泌專考試複習網站，無需安裝、不需後端、可離線使用。

涵蓋八個科別模組：腎細胞癌 RCC、泌尿道結石 Urolithiasis（顏敬恆，新增）、攝護腺癌 PCa、腎上腺・陰莖癌・睪丸癌、男性學・生殖泌尿 Andrology、排尿功能・女性泌尿、泌尿道感染・性傳染病・手術併發症、兒童泌尿學。

功能：左側科別／章節導覽、A–H 重點摺疊面板、中英文醫學名詞全文搜尋、表格手機橫向捲動、流程圖灰底區塊、「最後衝刺」高頻考點模式。

## 使用方式

直接以瀏覽器開啟 `index.html` 即可；或部署到 GitHub Pages 取得公開網址。

## 部署到 GitHub Pages

1. 將本資料夾內檔案上傳到 GitHub repo（至少要有 `index.html`）。
2. repo → Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main` / 根目錄 `/ (root)` → Save。
3. 等待數十秒，頁面上方會出現你的公開網址。
